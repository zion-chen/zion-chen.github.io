二、准备本机用于挂载到容器的目录

1.什么是挂载

挂载（Mount）是一个在操作系统、容器（比如 Docker）和文件系统中常用的概念，它的本质是：把一个存储位置（目录/硬盘/设备）连接到另一个目录，使它可以被访问和使用。

在 Docker 中的挂载

Docker 容器是隔离的，默认看不到宿主机文件。但通过挂载，可以把宿主机的目录映射到容器里使用。

  • /container/data：容器里看到的目录

2.在 Windows 端创建配置文件和持久化目录

新建[YourPath]/Docker/Redis/conf和[YourPath]/Docker/Redis/data两个目录，分别用于存储Redis配置文件和持久化文件。

三、准备配置文件

1.下载官方配置文件

在Redis的Github主页下载对应最新版本的配置文件。

下载后把配置文件复制到[YourPath]/Docker/Redis/conf目录下。

2.修改配置文件

有以下几项配置需要修改：

  • daemonize no：不用守护进程（后台运行）的方式启动，而是当作普通的进程启动。因为Docker本身就是独立的容器，可以方便地和Docker中的Redis单独交互
  • protected-mode no：关闭保护模式。开启的话，只有本机才可以访问Redis
  • #bind 127.0.0.1：注释掉这部分，使Redis可以外部访问
  • # aof-load-broken no：注释掉这部分，否则使用本机配置文件启动时会导致启动失败（配置冲突）
  • # aof-load-broken-max-size 4096：同上

四、启动容器

在终端中使用命令启动容器。

命令解析：
1️⃣ 端口映射

  • 宿主机端口 6380 → 容器内部端口 6379（本机已经有一个Windows端的Redis进程占用了本机的6379端口）
  • 外部访问 Redis 时使用 127.0.0.1:6380
  • 容器内部 Redis 默认监听 6379 端口

2️⃣ 挂载卷（Volumes）

  • 配置文件挂载
    • 宿主机路径 /D/.../redis.conf → 容器内部 /usr/local/etc/redis/redis.conf
    • 通过下面的命令让 Redis 使用你自己写的配置文件启动
  • 数据卷挂载
    • 宿主机路径 /D/.../data → 容器内部 /data
    • Redis 持久化数据（RDB/AOF）会存到这里，重启容器数据不会丢

3️⃣ 容器命名

  • 给容器取名字 my-redis
  • 方便后续操作：
    • docker stop my-redis
    • docker logs my-redis
    • docker exec -it my-redis bash

4️⃣ 镜像与命令

  • redis：使用 Docker Hub 官方 Redis 镜像
  • 启动命令：redis-server /usr/local/etc/redis/redis.conf
    • 显式告诉容器 Redis 使用你挂载的配置文件️

⚠️重点：如果不写 redis-server /usr/local/etc/redis/redis.conf，容器会使用默认配置，密码配置就不会生效
