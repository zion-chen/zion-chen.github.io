LeetCode 笔记01-Java基础数据结构

发表于2025-11-24|LeetCode 刷题

这份 Java LeetCode 数据结构速查表 专为算法面试设计。我将其分为核心容器、常用工具类、以及高频语法细节三个部分，尽量涵盖 95% 的刷题场景。

一、 核心数据结构 (Core Data Structures)

1. 数组与字符串 (Array & String)

最基础，但API容易混淆。

类型声明/初始化获取长度常用操作
Arrayint[] arr = new int[n];arr.length (属性)Arrays.sort(arr)
StringString s = "abc";s.length() (方法)s.charAt(i), s.substring(start, end)
StringBuilderStringBuilder sb = new StringBuilder();sb.length()sb.append(), sb.reverse(), sb.toString()

🔥 刷题 Tips:

  • Char Array: 字符串不可变，若需频繁修改字符，先转数组：char[] chars = s.toCharArray();。
  • String Pool: 比较内容一定要用 s1.equals(s2)，绝对不要用 ==。

2. 列表 (List - ArrayList)

动态数组，最常用的容器。

3. 哈希表 (HashMap & HashSet)

绝大多数O(1)O(1)O(1) 查找问题的解法。

4. 栈与队列 (Stack & Queue)

注意： Java官方推荐使用 Deque (双端队列) 接口，实现类用 ArrayDeque 或 LinkedList。不要用 Stack 类（它是同步的，慢且过时）。

5. 优先队列 / 堆 (PriorityQueue)

默认是小顶堆 (Min-Heap)。常用于 Top K 问题。

二、 必备工具类 (Essential Utilities)

1. Arrays 类 (操作数组)

2. Collections 类 (操作集合)

3. Math 类

4. 类型转换 (Conversions)

刷题中经常需要在 String, int, char 之间转换。

  • String -> int: Integer.parseInt("123")
  • int -> String: String.valueOf(123) 或 Integer.toString(123)
  • char -> int: c - '0' (利用 ASCII 码差值)
  • List -> Array: list.stream().mapToInt(i->i).toArray() (稍微慢点，但方便)

三、 常见算法模板变量

BFS / DFS 方向数组

在网格搜索（Grid Search）中非常常用。

比较器 (Comparator) 写法

用于自定义排序，如 Arrays.sort() 或 PriorityQueue。
